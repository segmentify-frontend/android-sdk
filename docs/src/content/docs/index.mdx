## What the SDK does

<CardGrid>
  <Card title="Tracks events" icon="rocket">
    Page and product views, basket and checkout steps, wishlist, search and
    user events, each with one method call.
  </Card>
  <Card title="Returns recommendations" icon="star">
    Event methods hand back the recommendation widgets set up in your
    Segmentify panel, ready for you to render.
  </Card>
  <Card title="Powers search" icon="magnifier">
    Instant search and faceted search results, with click tracking.
  </Card>
  <Card title="Reports push notifications" icon="email">
    Registers device tokens and reports views and clicks of push campaigns.
  </Card>
</CardGrid>
